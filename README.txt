TOP FORT — LANDING PAGE

ARQUIVOS
- index.html: página principal
- styles.css: visual responsivo
- script.js: menu e formulário para WhatsApp
- privacidade.html: rascunho de política de privacidade

COMO VISUALIZAR
1. Extraia todos os arquivos da pasta ZIP.
2. Abra index.html no navegador.
3. Para publicar, envie os arquivos para sua hospedagem estática com HTTPS.

CONFIGURAÇÃO OBRIGATÓRIA DO WHATSAPP
1. Abra script.js.
2. Troque CONFIGURE_SEU_NUMERO em WHATSAPP_NUMBER pelo número comercial real.
3. Use código do Brasil + DDD + número, somente dígitos. Exemplo ilustrativo: 5521999999999.
4. Teste o formulário no celular e computador.

OBSERVAÇÕES
- Não há backend. O formulário prepara a mensagem e abre o WhatsApp; não simula envio automático.
- Os preços, estoque, especificações e condições comerciais não foram inventados.
- As fotografias externas dependem de conexão com a internet e dos termos/licenças dos respectivos provedores.
